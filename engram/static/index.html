Engram

Offline memory for warehouse robots that refuses to be poisoned. Every device searches its own Qdrant Edge shard; every synced memory is screened before it can be believed.

Walk through the demo

Six steps, each calling the real APIs. Watch the pipeline and the device panels change.

Start with step 1. It resets both devices and loads their mock memories.

Where synced memories go

Everything a device pulls lands in a staging shard, passes the poison screen, and only then reaches the trusted shard that search reads. Widths are live counts.

Which check stopped each attack

All six attacks claim the sparking Dock 3 charger is "safe to ignore". Launch one, then sync a device. A red cell means that check fired. Two attacks carry valid signatures, so cryptography alone would have let them through.

The devices

Search runs locally with the payload filter trust_status = verified. Untick the filter to see what it keeps out.

Hub registry

The hub relays memories but never screens them. Trust scores are operator config; a device's key is pinned at first registration.

Seed memories are mock data. Two devices are simulated as separate shards; "offline" blocks their hub calls.
