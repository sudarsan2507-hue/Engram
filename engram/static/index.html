What the robot trusts

    Sync pipeline

    Everything a device pulls lands in a staging shard, passes the poison screen, and only then reaches the trusted shard that search reads. Widths are live counts.

    Devices

    Each device searches its own shard with the payload filter trust_status = verified. Untick the filter to see what it keeps out.

    Attack lab

    Every attack claims the sparking Dock 3 charger is "safe to ignore". Launch one, then sync a device. A red cell marks the check that fired. Two attacks carry valid signatures, so cryptography alone would have let them in.

    Conflicts

    When honest devices disagree, each value scores average trust × recency decay × agreeing devices. Both devices use the same registry trust, so they reach the same answer. Losers are marked superseded, never rewritten.

    What the filter costs

    Vector search latency per query over 50,000 memories, query embedding excluded, log scale. Measured by benchmark.py on a laptop CPU.

    Hub

    The hub relays memories but never screens them. Trust scores are operator config, and a device's key is pinned the first time it registers.
